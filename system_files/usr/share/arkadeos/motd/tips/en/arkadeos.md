the Windows game stores (Battle.net, EA, Ubisoft) install from the Portal in one click, GE-Proton included.
apps, stores and AI tools are turned on and off in the ArkadeOS Portal: `arkadeos-portal`.
the system updates itself every day; the new version starts at the next restart.
if something is wrong after an update, this takes you back to the previous system: `sudo rpm-ostree rollback`.
command-line tools go to your own folder with Homebrew, the system stays untouched: `brew install <name>`.
